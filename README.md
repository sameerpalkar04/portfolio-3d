# Sameer Palkar — Home Office Portfolio

An interactive home-office walkthrough that leads to Sameer’s portfolio. Explore the room, then open the portfolio at the work desk.

## Run locally

1. Install Node.js 20.19+ or 22.12+.
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local address shown in the terminal.

## Controls

- Desktop: hold the up/down arrows to walk and left/right to turn. Drag the view to look around. Press Enter near the work desk to open the portfolio. Press Backspace or Delete to close it.
- Mobile: press and hold the on-screen direction buttons. Move to the highlighted desk and use the on-screen Enter prompt.
- Use the Day/Night switch in the home-office plan to change the exterior sky and room lighting.
- Inside the portfolio desktop, select About Me, Projects, Resume, Skills, or Contact from the app list or dock.

The walkthrough uses the supplied home-office 3D model and its embedded materials. Google Fonts are requested when a connection is available; the system font stack is used otherwise.
